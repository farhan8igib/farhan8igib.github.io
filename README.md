## How to update the website in future

### Personal details and metrics
Open `index.html` and search for the metric or text you want to change.

### Research / career text
- `about.html` = biography and career timeline
- `research.html` = research programmes
- `publications.html` = selected publications

### Contact details
Update `contact.html`.

### Your photo
Replace `assets/images/mohammad-farhan.jpeg` with a new image using the same filename.

### Publishing changes
After making changes:
1. Upload the changed files to the GitHub repository.
2. GitHub Pages will automatically rebuild the site.
3. Wait about 1–2 minutes and refresh `https://farhan8igib.github.io`.

For future versions, I recommend keeping the website data in a separate `data` folder so that metrics and publications can be updated without editing HTML.
